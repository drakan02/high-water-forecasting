## Checklist and evidence

- [x] P5 evaluation only joins forecast output to target labels after forecasts were saved. Target H is absent from forecast generation. It requires a forecastable origin, observed/eligible target, and both predictions for a cycle to be paired.
- [x] Metrics are MAE, RMSE, bias, paired count, monthly metrics, gains, coverage, per-cycle scored rows and error histograms. A separate verification recomputed MAE/RMSE/bias from each scored Parquet by split and matched all reported metrics within `1e-9`.
- [x] Paired samples: validation 2006 n=650; chronological test 2007 n=701; retrospective in-sample 2007 n=701; transfer test 2010 n=645. The retrospective result is explicitly in-sample.
- [x] Chronological 2007 gauge-only MAE/RMSE: harmonic 25.3412/31.8247 cm; ECM 16.2892/22.2337 cm. Frozen-transfer 2010: harmonic 21.8626/27.3733 cm; ECM 14.6339/18.7231 cm. These are total-H gauge-only scores, not paper-comparable results.
- [x] 2010 transfer harmonic baseline was fit from available observations during 1990–2009 (150,554 fit observations; UTide 0.4.0, 68 auto constituents, latitude 51.50775°, trend and nodal corrections enabled, confidence intervals disabled). UTide is not asserted equivalent to the paper's EHM. Reconstructed context covers 2008–2011; 681 of 705 2010 target cycles pass peak-label QC.
- [x] Frozen OLS correction fit uses 684 valid 2009 rows (rank 4/4), then issued 705 candidate 2010 forecasts; 657 forecast inputs were available, 48 candidates excluded, and 645 targets were paired for scoring. Model coefficients and source hashes are in the P5 transfer outputs.
- [x] All 16 `delta_vs_paper` fields are null. No 2007 CS3X surge residual or grid mapping is available; therefore this P5 branch does not claim Table 1b reproduction. It never treats `H−A` as surge.

Evaluation CLI and guarded transfer/ECM CLI succeeded; logs are `reports/p5_evaluation_run.log`, `reports/p5_transfer_2010.log`, and `reports/p5_transfer_2010_ecm.log`. `git diff --check` passed.
